pairdesk

What it is

Chat
unique usernames, friend requests, DMs, groups. Server stores ciphertext only.
Remote help
the admin can watch or board a friend's terminal, or view their screen, only with consent.
Standing grants
trust the admin once; revoke any time. Sudo stays blocked unless you say otherwise.
Logs you own
every command, its output and every file touched, hash-chained and signed on your machine.

Security in one paragraph

Nothing listens on your machine; every connection is outbound. Chat is encrypted with keys derived from device identities the server never sees. Remote sessions run peer to peer over WebRTC with a Noise handshake bound to those identities. The admin's own account needs a second device factor and a local passphrase. Grants are signed by you and enforced by your client, not by the server.
